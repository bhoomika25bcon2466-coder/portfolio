# Personal Portfolio Website

## About the Project

A personal portfolio website developed using **HTML, CSS, and Cursor AI** to showcase my technical skills, projects, and professional profile as a B.Tech Computer Science Engineering student. The website serves as a central platform to present my background, highlight my development projects, and demonstrate my growing expertise in programming and web development.

The portfolio features a clean, user-friendly interface with dedicated sections for personal information, technical skills, projects, and other professional details. It also integrates an **AI chatbot** to provide an interactive user experience and a **weather checker** to help users explore weather information.

## Key Features

- **Personal Profile:** Showcases my introduction, educational background, technical skills, and career interests.
- **Projects Showcase:** Displays my development projects with descriptions, technologies used, and key functionalities.
- **AI Chatbot:** Provides an interactive conversational interface to enhance user engagement.
- **Weather Checker:** Allows users to check weather information through an integrated weather feature.
- **Responsive User Interface:** Uses CSS styling to create a clean and accessible layout across supported screen sizes.
- **Structured Web Pages:** Uses HTML for page structure and CSS for visual presentation.
- **AI-Assisted Development:** Built and refined with Cursor AI to assist with code generation, debugging, and improvements.
